kp-sync documentation
=====================

Synchronize one KeePass database through a local hub and verified version
history, without choosing winners by modification time.

This manual separates user integration, experimental Python interfaces,
and internal implementation reference. Building it never runs the daemon,
loads a profile, reads a keyring, or contacts an endpoint.
